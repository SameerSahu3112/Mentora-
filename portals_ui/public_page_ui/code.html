How Enrollment Works: Step-by-Step

Mentora prohibits impersonal automated checkouts. Every aspirant is evaluated, mapped to the correct batch capacity, and manually verified before access is granted.

STEP 01 travel_explore

Browse Course & Pick Target Batch

Examine Rise, Spark, or Apex. Confirm live seat availability with zero-overbooking safeguards enforced directly at the database level.

• Capacity strictly capped at 50 per batch
STEP 02 badge

Submit Student Application

Provide student name, academic grade (Class 9–12 / Dropper), contact number, and target exam year. Unique Student ID generated immediately.

• Instant tracking ID allocated
STEP 03 call_quality

Free Introductory Phone Call

Within 7 days of application, an Admin or NIT mentor calls the student and parent to audit syllabus completion and set realistic targets.

• Direct 1:1 strategy alignment
STEP 04 account_balance_wallet

Manual Payment Recording

Direct UPI or bank transfer recorded by the administrator. Transaction reference is cataloged with timestamp & amount verification.

• Secure, non-automated accounting
STEP 05 admin_panel_settings

Admin Activation Protocol

Two-admin security clearance locks the student to the selected batch schedule, unlocks learning materials, and assigns the primary mentor.

• Portal credentials dispatched via SMS/Email
STEP 06 event_available

Access & Weekly 1:1 Mentorship

Immediate access to practice sheets and video modules. Regular weekly batch sessions and bookable personal mentor slots until Exam Date + 7 Days.

• Guaranteed post-exam buffer
